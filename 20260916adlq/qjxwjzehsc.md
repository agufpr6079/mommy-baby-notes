# 港城福音，妇保院又一“首例”成功!

> 更新时间：2026-09-16 (UTC+8)

下午四点左右，乳腺保健科主任周晓春刚结束了一台手术，他快速换下手术服，还没来得及回办公室，直接往姚女士（化名）的病房走去。

**成功首试**

姚女士，今年36岁，15年前因美观需求做了双乳丰乳手术。近日，姚女士感到乳房胀痛不适，前来就医。

经诊断，姚女士乳房变形已有两年，需将乳腺假体取出。考虑到患者还很年轻，术后要达到最快最好的恢复效果，不影响今后正常生活。经全科病历讨论，决定对患者进行全麻下的腔镜乳腺微创假体取出手术。

次日，在各项术前检查完善后，由麻醉科和手术室全力配合，乳腺保健科主任周晓春和乳腺保健科副主任医师周培杰及邓勇医师组成的手术组对该患者进行了乳腺腔镜微创假体取出术。

手术中，在乳腺下皱襞做了两个小孔，将带有摄像头的内镜置入体内，放大后的图像转播到高清显示器上，手术医师通过观察显示器画面，可精准的观察并切除病变组织。同时使用美国GE便携超声将变形移位的乳腺假体从乳房各个角落找出来，手术历时2个小时，术后各项体征正常，转入病房留院观察。

**术后一笑**

主刀医生周晓春（右）、周培杰（左）

**最佳治愈**

周晓春一直惦记着姚女士的术后恢复情况，但他进入病房后，只见床位上躺着一人，戴着眼罩，翘着二郎腿，正沉浸在音乐的世界里。周晓春心下纳闷，问道：“这张床位的姚女士去哪儿了？”女士摘下面罩，大笑：“周医生，就是我啊！”周晓春这才看清，这位可不就是上午刚做完手术的姚女士。

周晓春详细询问了她术后的各种情况，一切正常。姚女士笑着说：“周主任，我感觉跟没做手术一样，是不是今天就可以出院了……”

看到病人如此自在舒适，周晓春一直悬着的心终于落地。

**优质方案**

近年来，腔镜技术的广泛应用对外科手术产生了重要影响，并发展到乳腺、甲状腺等本无腔隙的实质性器官疾病的外科治疗。**乳腺腔镜手术的优点在于手术的微入路、组织损伤小、康复快，尤其切口美容是开放性手术所不能达到的，弥补了传统手术的缺陷和不足。**

**乳腺腔镜手术还适合于哪些领域？**

1. 男性乳腺增生和发育；

2. 乳腺良性肿瘤的乳腺局部切除术；

3. 乳腺恶性肿瘤的保乳手术、乳房再造手术；

4. 浆细胞性乳腺炎和肉芽肿性乳腺炎；

5. 乳腺假体植入和取出手术。

**腔镜乳腺手术在医学界不是新技术，但是连云港此前还未有过成功案例，此次连云港妇幼成功完成首例腔镜乳腺手术，对港城百姓来说，可谓大大的福音。**
