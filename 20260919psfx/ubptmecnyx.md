# 糖耐没通过的孕妇可以采取哪些办法来控糖？

> 更新时间：2026-09-19 (UTC+8)

糖耐没通过的孕妇可以采取这些方法来控糖，如做到少食多餐、主食要少“精”多“粗”、减少脂肪的摄入、烹饪方式“懒”一点儿、放慢吃饭速度等等。糖耐是诊断糖尿病的一种实验室检查方法，主要有静脉和口服两种，静脉葡萄糖耐量试验适用于胃切除后或者吸收不良综合征等特殊病人，口服葡萄糖耐量试验（OGTT）则是临床最常见的检查手段。

## 糖耐没通过的孕妇怎么办

孕妇在孕24-28周去医院做糖耐的时候，有些孕妇是不能通过的，而有些孕妇则是检查顺利，对于糖耐检查没有通过的孕妇来说，可以通过以下方法来控糖。

- 1. 在控制总热量的原则下要保证营养的全面与均衡，可以将每天应摄取的食物分成5-6餐进食，特别要注意，晚餐与第二天早餐的时间不要过长，如果睡前一餐吃的比较早，可以在临睡前补充一些食物，比如喝杯牛奶、吃一小片苏打饼干；
- 2. 精白细软的食物升血糖的速度比较快，而那些富含膳食纤维的全谷物和杂豆类食物，如燕麦、荞麦、红小豆等，消化吸收速度比较慢，餐后血糖上升也比较慢，如果主食用粗粮或杂豆类来替代，或者把粗粮杂豆和精米白面混合在一起吃，就能在很大程度上降低餐后的血糖波动；
- 3. 摄入脂肪过多会造成热量摄入超标，不仅可造成血糖升高，还易诱发妊娠期高血压等疾病，高脂肪食物包括所有油炸食物、蛋糕甜品、五花肉等肥肉、大部分坚果以及荤汤等；
- 4. 在厨房要“懒”一点儿，蔬菜能不切就不切，能生吃的就生吃，其是煮粥的时候要尽可能“凑合”，急火煮少加水；
- 5. 饱腹感会在吃进食物后约20分钟才能感知到，如果吃饭速度太快则很容易吃得过饱，进而摄入过多能量，因此妊娠糖尿病孕妈可在进食时放慢速度，每口都多嚼一会儿再咽下，每餐只吃七分饱，自我感觉适中即可，尤其不要打扫剩饭。

值得一提的是，孕妇糖耐检查没有通过的时候，可以通过食多餐、主食要少“精”多“粗”、减少脂肪的摄入、烹饪方式“懒”一点儿、放慢吃饭速度等方法来控糖，以免出现高糖现象，从而不利于胎儿的正常发育。
